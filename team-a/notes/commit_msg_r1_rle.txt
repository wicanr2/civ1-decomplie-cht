# 算法細節

  decode 是 straight-forward (~30 行 C). encode 是 greedy:
    - count_run(p): 看 p[0..] 連續同值 byte 數 (cap 127)
    - 若 run >= 2: 出 [run] [byte]
    - 否則: 累積 literal 直到遇到 run >= 2 或 cap 127

  邊界 case 處理:
    - 全零 1024: 8 個 [127][0] + 1 個 [8][0] = 8×2 + 2 = 18 byte ✓
    - 全唯一 256: 2 個 [0xFF][127 bytes] + 1 個 [0x82][2 bytes] = 259 byte ✓
    - count 0 視為 no-op (decoder 容忍), encoder 不產生
