# Ghidra LoadGifPicture 嘗試 (部分失敗,待續)

寫 team-a/tools/ghidra_extract_loadgifpicture.py 想找 gr_pic.c
家族 5 個函式 (GR_PicRead / GR_PortDataToBitmap / LoadGifPicture /
InvertBitmap / PicDecompress) 的 caller。

策略: 「ref Borland assert string 的 function 就是該函式自己」
失敗原因: Ghidra auto-analysis 沒建立 segment 1420 assert string
的 data reference, 5 個 string 全部 getReferencesTo() 回空。

待續 strategy:
  (a) byte pattern scan code segment 找 PUSH 0x2372 等 immediate
  (b) 重跑 auto-analysis 並打開 data reference walker
  (c) 跳過 Ghidra, 直接從 CvPc payload bytes 反推 LZW 變體
      (RLE+LZW / 早字典 update / 9-bit forced 等多種試)

不擋 M0 / M1 / M2; M3 之前 (RSC + CvPc decode) 必須解出 LZW 變體。
