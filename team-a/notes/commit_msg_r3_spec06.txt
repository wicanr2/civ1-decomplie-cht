# 重大發現

  1. **Wiki 對 4 個 unit 錯誤** (manual 是 ground-truth):
     - Legion: 3-1 不是 4-2
     - Musketeers: 2-3 不是 3-3
     - Riflemen: 3-5 不是 5-4
     - Fighter: 3-3 不是 4-2
     - Frigate move=3 不是 4

  2. **Unit stats 不存於 CIV.EXE / 5 RSC / 3 SAV 任何位置作為
     contiguous 28-byte 陣列**:
     - manual ground-truth 全 4 個 array (attack/defense/move/cost) 都 0 hit
     - 包括 (a,d) interleaved 56-byte / (a,d,m,cost) 112-byte 都 0 hit
     - 結論: stats hardcoded 在 code segment 用 MOV immediate 初始化
     - v0.2 R4 用 Ghidra cross-ref + MOV pattern walk 補

  3. **data_units function decompile (FUN_11e8_0337) 證實**:
     - 它不是初始化 unit stats, 是載 STR# 143/144/145/146/135 names
     - 跟 SAV §7.2 spec 對位完全一致 (offset 0x12d8+0x3DA/0x2DA/0x1DA
       對應 SAV file 內 0x112/0x212 etc.)
     - 真正 unit stats init function 還沒找到

  4. **Manual P35 Combat formula**:
     - Chariot (A=4) vs Phalanx (D=2): Chariot 勝率 = 4/(4+2) = 66.7%
     - Combat = single dice roll, ratio = A / (A+D)
     - 修飾: Veteran ×1.5 / Walls ×3 / Fortified ×1.5 / Terrain bonus
     - Team B 可直接實作 (spec 06 §6.1.1)
