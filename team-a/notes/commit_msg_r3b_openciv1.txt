# 重大發現 (R3b)

  1. **OpenCivOne 揭穿 Fighter 4-2** (不是 manual 寫的 3-3!)
     - manual P41 Fighter "3-3-10" 是 印錯
     - OpenCivOne (從 1991 DOS binary v475.05 RE) 確認 4-2
     - 我們的 R3 spec 06 v0.1 用 manual 3-3, R3b v0.2 修正為 4-2

  2. **OpenCivOne 揭穿 UnitDefinition 34-byte struct**:
     - 12-byte name (ASCII null-pad)
     - 11 × LE16 fields (CancelTech / MovementType / MoveCount /
       TurnsOutside / Attack / Defense / Cost / Sight / Cargo /
       AIRole / RequiredTech)
     - Cost 是 shields/10 (Settlers cost=4 → 40 shields)

  3. **1993 Win port struct ≠ 1991 DOS struct**:
     - 1991 DOS (OpenCivOne base): 34 byte 含 name
     - 1993 Win: "Settlers" 字串只在 error messages 出現,
       不在任何 unit table 內. 推測 Win port 拆 name 進 STR# 132
       (per spec 05), unit table 純數值 ~22 byte
     - 這是 Mac port + Win shim 的副產物 (spec 01 §1.2),
       Mac 自然把 name 跟 stats 分離成 Resource

  4. **Wiki 對 Civ1 unit stats 多項錯** (manual + OpenCivOne 都修):
     - Legion 3-1 (wiki 4-2) ✗
     - Musketeers 2-3 (wiki 3-3) ✗
     - Riflemen 3-5 (wiki 5-4) ✗
     - Fighter 4-2 (wiki 4-2 對, manual 3-3 錯)
     - Frigate move=3 (wiki move=4 ✗)
