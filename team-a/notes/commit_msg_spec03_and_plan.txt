# Agent A (general-purpose) - spec 03 資產格式與 tile 抽取

顛覆性發現: 1993 Windows 版**沒有 .PIC 檔**, 33 個資產檔組成:
  5 個 .RSC (Apple Mac Resource Fork 標準格式)
    Civdata0..4: 含 199 個 CvPc + 33 STR# + 399 TEXT + 7 GDAT + 14 KDAT
  1 個 CIV.EXE (Win16 NE) + CIVFONTS.FON + CIVHELP.HLP + MPLOGO.BMP
  23 個 .WAV (14 領袖語音 + 9 音效)

這直接證實 spec 01 §1.2 對「Win 版是 Mac port、resmgr.c 是 Mac
Resource Manager port」的論斷 — 檔案層證據。

**推翻** Track A PROJECT_MEMORY 的「.RSC 裡面沒有文字」結論:
  33 STR# + 399 TEXT = 432 條文字資料, 是 Batch B/C/D/E 翻譯
  規模的富礦。

**未解的關鍵**: CvPc payload 是 LZW 變體 (推測 RLE+LZW 混合),
標準 GIF89a decoder 17 個 code 後撞牆。前 16 個 code 解出**正確的
灰階 ramp**證明 container + root code size 都對。真正解唯有
Ghidra 看 gr_pic.c::LoadGifPicture (spec 01 §1.2 已標)。本次先
ship 已解部分, spec 03 §9.1 留給後續。
