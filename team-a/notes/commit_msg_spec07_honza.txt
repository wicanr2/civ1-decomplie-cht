# 重要發現

  1. SPR32X32 用 sheet 自帶 palette (sample pixel) **不是 fallback** —
     palette 內含 national + barbarian color, 是 game engine 設計的.
     之前我們 D-minimap 用 hardcoded RGB + nearest 是對的 fallback,
     精確版可以 read sentinel pixels 拿 national color.

  2. SAV file 用純 byte stream RLE (不是 bitstream, 不是 LZW),
     算法 100 行內可實作. 接通後 M6-full save 半解, 剩 SAV 解壓後
     city/unit 表 layout 仍 blocker.

  3. 原版 layout 跟我們 M6-minimap 差距:
     - title bar: 原版 Win16 "CIVILIZATION" + min/max, 我們是窄 menu bar
     - menu: 原版 8 個 item (File/Edit/Orders/Advisors/World/Civilopedia
       /City/Help), 我們 5 個 (少 File/Edit/City/Help)
     - World Map / Status 是獨立 Win16 子視窗有自己 title bar,
       我們嵌入主 widget. (M5-D polish 可加)
     - 主地圖缺 city sprite + city name label (M6-full city 系統)
     詳見 docs/screenshots/reference/README.md

  4. Honza Readme.txt 明示「14 個失敗 CvPc」可能是 MIDI-prefixed
     (spec 03 §9.4 已標), 不是 LZW 變體問題. 我們的 spec 03 §9.1
     6-byte header 對 (Honza 算法一樣).
