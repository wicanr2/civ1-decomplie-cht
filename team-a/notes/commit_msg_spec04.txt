Spec 04: 24 RT_DIALOG 全解 + RANDOM* widget family 揭穿

# 工具

  team-a/tools/ne_dialog_dump.py
    Win16 NE RT_DIALOG parser
    - 從 NE resource table 抽 type 0x8005
    - 解 DLGTEMPLATE (style / cdit / x,y,cx,cy / menu / class /
                     caption / 可選 font)
    - 解 DLGITEMTEMPLATE (14 byte header + 變長 class / text /
                         cb_data)
    - item.class 用 0x80-0x85 單 byte ordinal (Win16 慣例)
    - CLI --id N 單一 / --json 機器讀
  team-a/dumps/04a_dialogs.txt   人讀
  team-a/dumps/04b_dialogs.json  Team B 消化用

# 重大發現

24 個 dialog 全用自製類別 CIVDIALOG, 由 CIVDIALOGPROC @ 1098:1838
(spec 02 §2.2.5) 統一 paint + dispatch。
caption 全為空 - 標題由 paint handler 自繪。
Track A 的 Big5 patched captions 全部正確顯示: 確 / 結束 / 取消 /
前往城市 / 先存檔 / 上一頁 / 中止 等。
Dialog 138 顯式設 CIVTIMES12 字型 (CIVFONTS.FON 內 21 個
RT_FONT 之一)。

# RANDOM* widget family 完整揭穿

Dialog 2000 是廢棄 / 未刪的 UI showcase, 含 9 個自製類別:

  RandomRadio       -> RANDOMRADIOPROC @ 1058:06ab (spec 02 §2.2.9)
  RandomStatic      -> RANDOMSTATICPROC @ 1058:081a (spec 02 §2.2.10)
  RandomUser        -> RANDOMUSERPROC @ 1058:0921 (spec 02 §2.2.11)
                       retail dialog 最常用 -
                       #135/#136/#139/#146/#147/#149/#999 都用到
  RandomCheck
  RandomHorzBump
  RandomVertBump
  RandomHorzMeter
  RandomFrame
  RandomRectangle

spec 02 推測時沒列後 6 個 - 現在揭穿。Team B M4+ 寫 dialog 系統時
要實作這 9 個 widget 變體。
