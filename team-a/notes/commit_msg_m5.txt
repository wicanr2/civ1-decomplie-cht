M5: world map + sprite sheet + grid blit (tile 語義校驗待 spec 06)

依使用者「1 > 2 > 3 依序」#1 任務。M5 範圍：

# 交付

  src/world/sprite_sheet.{c,h}   sprite sheet 切割 + palette LUT cache
                                  - civ_sprite_sheet_load: 從 .RSC CvPc
                                    解碼 + 自動算 cols/rows
                                  - civ_sprite_sheet_build_lut: 一次性
                                    建 sheet palette -> base palette LUT
                                  - civ_sprite_rect: (col, row) ->
                                    src rect

  src/world/world.{c,h}          世界地圖 + cursor + view
                                  - civ_world_t: terrain[H=30][W=60]
                                    uint8_t array
                                  - civ_world_init_demo: bands 為不同
                                    tile_idx 視覺校驗
                                  - civ_world_move_cursor: 鍵盤導覽 +
                                    視窗邊緣 auto-scroll (margin 2 tiles)

  src/civ_game.h                 加 civ_sprite_sheet_t + civ_world_t +
                                  world_ready flag

  src/widgets/map.c              map_render M5 升級
                                  - world_ready true 時走 sprite sheet
                                    blit path:
                                    * for each visible tile, look up
                                      world.terrain[wy][wx]
                                    * decode tile_idx -> (col, row)
                                    * civ_sprite_rect + blit
                                      (lut_built ? blit_remap : blit)
                                    * cursor 雙框 (gold)
                                  - world_ready false 時保留 M0..M4
                                    fallback (placeholder 綠底)

  tests/test_world_snapshot.c    視覺校驗
                                  - load SPR32X32 (CIVDATA4 #200,
                                    1472x400)
                                  - 自動算 46 cols x 12 rows of 32x32
                                  - debug 模式:
                                    * g.palette = sheet.pal (用 sheet
                                      自有 palette 顯示正確顏色)
                                    * world_ready=false 跳過 map widget
                                    * 直接 civ_surface_blit sheet 切片
                                      到主地圖 widget rect (480 wide
                                      = 15 cols 可見)
                                    * 32x32 grid 線疊加肉眼可數
                                    產出 docs/screenshots/m5_world.png

# 視覺校驗結果

可看到 SPR32X32 內 SHEET 結構 (15 cols 可見):
  Row 0:        紅 bg + 上排工具列 sprite (cols 8-14)
  Row 1:        forest 小 icon (cols 1-5) + 牆/建築 (cols 13-14)
  Row 2:        **COAST/RIVER 水紋 (cols 0-14)** 真實 terrain
  Row 3:        馬/鹿/棕地/山等特殊 terrain
  Row 4-5:      villagers walking + cannon sprite
  Row 6-7:      軍事步兵 + 海軍單位

實際 TERRAIN 大塊位於 cols 14-29 (在 1472 sheet 中央, 本 480px
視窗看不到), spec 06 校驗時需用更寬視窗或捲動到 col 14+ 確認。
